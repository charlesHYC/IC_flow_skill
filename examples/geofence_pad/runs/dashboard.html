PAD 模式要知道的事

  • PAD_LIMITED 不是 PASS：腳本已確認核心區 DRC 為 0、所有 MOS／電阻都對上，剩下的錯誤在 SAED32 io_std library 內（LEF／GDS／CDL 不一致）。
  • LVS 中 VDD／VSS／VDDIO／VSSIO 在 layout 併成同一個 net，是 IO library 造成的（拿掉 PAD→ring 接線也一樣）。
  • 要乾淨的 DRC／LVS 證據，另外用 USE_PAD 0 跑核心。
